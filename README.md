# Gyeongmin Kim

Software engineer, applied AI practitioner, technical educator, and author focused on building measurable, production-oriented software systems.

## Professional Profile

- Software development experience since 2000 across application software, embedded software, infrastructure consulting, and R&D leadership.
- Currently serving as **Deputy General Manager, Development Team 1**.
- Appointed **Korea Industrial Field Professor** in Information and Communications / Information Technology for 2025-2027.
- Registered software copyright holder for **T-IDEA on AltCLIP-Based Industrial Anomaly Detection System**.
- Current interests include spec-driven development, AI coding agents, retrieval-augmented generation, industrial computer vision, token-efficient systems, cybersecurity, and developer productivity.
